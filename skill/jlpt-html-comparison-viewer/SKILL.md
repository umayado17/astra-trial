# jlpt-html-comparison-viewer

原文とJLPTレベル別（N5前半〜N1後半のうち、ユーザーが指定した1〜10段階）に書き換えたテキストを並べて比較し、語彙・文法・文構造の変化および原文到達度（スキャフォールディングの推移）をカラーハイライトとマトリクスで直感的に分析できる単一ファイルのHTMLアーティファクトを生成するスキルです。

## When to Use

  - ユーザーがJLPTレベル別の変換テキストと原文を比較できるHTMLアーティファクトやビューアの作成を求めたとき
  - 「どこがどう変わったのかわかるHTMLにして」「前回と同じ書式のHTMLアーティファクトにして」と指示されたとき
  - 日本語教育の読解教材として、生教材（原文）と特定レベル（1レベル、複数レベル、または全10段階）の差分を可視化したいとき

## レベル指定・標準ラベリング定義（10段階）

ユーザーがどの呼び方（JLPT表記・段階名・教科書進度）でレベルを指定しても以下の10段階に正確にマッピングし、**HTMLビューア上のレベル選択ボタン、レベル概要カード、マトリクス表、一覧カードの見出しすべてにおいて、JLPT表記（`code`）と標準サブタイトル（`sub`）を併記して表示する**こと。

| 段階 | JLPT表記 (`code`) | 標準サブタイトル・別名ラベル (`sub`) |
| :--- | :--- | :--- |
| **1** | **1. N5前半** | 入門、みんなの日本語13課相当（１３課相当） |
| **2** | **2. N5後半** | 初級前半、みんなの日本語25課相当（２５課相当） |
| **3** | **3. N4前半** | 初級後半、みんなの日本語38課相当（３８課相当） |
| **4** | **4. N4後半** | 初中級前半、みんなの日本語50課相当（５０課相当） |
| **5** | **5. N3前半** | 初中級後半、書き言葉 |
| **6** | **6. N3後半** | 中級前半、中級 |
| **7** | **7. N2前半** | 中級後半、実務・一般ニュース |
| **8** | **8. N2後半** | 中上級、ビジネス実務 |
| **9** | **9. N1前半** | 上級、ビジネス日本語（※原文100%到達ゴール時は `上級、ビジネス日本語（原文100%到達）`） |
| **10** | **10. N1後半** | 超級、ネイティブレベル（※上限ロック時は `超級、ネイティブレベル（上限ロック）`） |

  - **UI上の表示フォーマット例**：
      - レベル選択ボタン：上段に太字で `1. N5前半` と到達度 `%`、下段に小さめの文字（`text-[11px] opacity-85 mt-1 leading-tight w-full`）で `入門、みんなの日本語13課相当` を折り返し可能にして全文表示（`truncate` で省略しないこと）。
      - レベル概要カード・一覧カード見出し：`1. N5前半` と `入門、みんなの日本語13課相当` を併記する。

## 原文の客観レベル表記の統一ルール（画面4か所）

原文の客観レベルを表す文字列（例：原文が9段階目相当なら **`9. N1前半（上級、ビジネス日本語）相当`**、8段階目相当なら **`8. N2後半（中上級、ビジネス実務）相当`**）は、必ず `【番号. JLPT表記（標準ラベル）相当】` の書式に統一し、以下の**画面4か所すべてで一言一句同じ表記に揃える**こと。

1.  **原文カード（`#originalTextCard`）右上の緑のラベル**：
    `客観レベル：9. N1前半（上級、ビジネス日本語）相当`
2.  **段落比較（`#sectionCardsContainer`）の左列「【原文】」の見出し**：
    `【原文】（9. N1前半（上級、ビジネス日本語）相当）`
3.  **主要表現マトリクス（`#matrixTableBody`）の原文の行**：
    `【原文】<br><span class="text-[11px] text-emerald-700">9. N1前半（上級、ビジネス日本語）相当</span>`
4.  **全段階一覧（`#allLevelsContainer`）の原文カードの見出し**：
    `【原文】〇〇（客観レベル：9. N1前半（上級、ビジネス日本語）相当）`

※なお、各レベルの `grammarGuide`（解説文）の文章中における自然な言及（例：「原文の客観レベル（N1前半相当）に到達。」など）は文章の一部であるため、無理に括弧を重ねず自然な文章のままでよい。

## 最重要原則：指定レベル数に応じた動的レイアウト（スコープ適応の原則）

ユーザーが指定した変換対象レベルの数（$N$個）に応じて、HTMLビューアに含めるデータとUIレイアウトを動的に最適化すること。**指定されていないレベルを勝手に追加して常に10段階表示にしてはならない。**

1.  **単一レベル指定時（$N = 1$ / 例：「原文をN3前半にして」「みんなの日本語25課相当にして」）**
    
      - **データ**：指定された1レベルと原文のデータのみを含める。
      - **不要なUIの非表示**：レベル切替ボタンバー（`#levelSelectorBar`）は非表示にする（切り替える対象がないため）。
      - **ビュー構成**：「段落ごと原文比較（上部：原文全文カード＋レベル概要カード、下部：3カラム比較カード）」と「主要表現の対照表」「全文通読カード」で構成する。

2.  **複数レベル部分指定時（$2 \le N \le 9$ / 例：「入門、初級前半、初級後半に変換して」）**
    
      - **データ**：指定された $N$ 個のレベルと原文のデータのみを含める。
      - **レベル選択ボタンバー**：指定された $N$ 個のボタンが美しく並ぶグリッド（例：3レベルなら `grid-cols-1 sm:grid-cols-3`、4レベルなら `grid-cols-2 md:grid-cols-4`）に自動調整する。
      - **マトリクス＆一覧モード**：指定された $N$ レベル＋原文のみで行・カードを構成する（タイトルも「主要表現 3段階マトリクス」「全3段階一覧」のように指定数に合わせる）。

3.  **全段階指定時（$N = 10$ / 例：「10段階で書き換えて」「N5前半からN1後半まで全部」）**
    
      - 全10段階のデータを含め、10個のレベル選択ボタン（`grid-cols-2 sm:grid-cols-5 lg:grid-cols-10`）、10段階マトリクス、全10段階一覧のフルスペックUIを構築する。

## Steps

### 1\. 対象レベルの特定と原文の客観レベル判定

1.  ユーザーの指示（または直前の変換結果）から、表示すべき対象レベル（1個、複数個、または全10段階）を特定する。「みんなの日本語38課相当」「中上級」などの別名ラベルで指定された場合も、上記の標準ラベリング定義に従って該当レベルを特定する。
2.  原文を意味のまとまり（見出し、リード文、各段落など3〜6セクション程度）に分割する。出典URLや出典元名称（新聞社名・メディア名など）がある場合は `originalData.sourceUrl` / `originalData.sourceLabel` として保持する。
3.  `jlpt-level-text-converter` の基準に従い、原文の客観レベル（10段階のどこに該当するか）を特定する。「原則：原文よりは難しくしないこと」に基づき、原文の客観レベルを100%到達ゴール（上限キャップ）とし、それより上のレベルが対象に含まれる場合は「上限ロック（原文維持）」として扱う。

### 2\. カラーハイライト（4種）のマークアップ設計

HTML内で原文と変換テキストの差分を明示するため、以下の4つのCSSクラスを使い分ける。

  - `.hl-orig`（グレー背景 `#f1f5f9` ＋破線下線 `#64748b`）：原文の比較対象となる重要表現・難語。
  - `.hl-vocab`（黄色背景 `#fef08a` ＋実線下線 `#eab308`）：語彙の平易化・言い換え（漢語から和語・具体物への置換など）。
  - `.hl-grammar`（水色背景 `#bae6fd` ＋実線下線 `#0284c7`）：文法・文構造の調整（単文化、接続詞による結合、初〜中級文型への書き換え）。
  - `.hl-match`（緑色背景 `#bbf7d0` ＋実線下線 `#16a34a`）：そのレベルで解禁され、**原文の表現・語彙に完全到達（一致）した箇所**。
  - 初級レベル（N5〜N4）の漢字には適切に `<ruby>漢字<rt>かんじ</rt></ruby>` タグでルビを振る。

### 3\. インタラクティブUIの実装（必須セクションと運営者クレジット表記）

単一のHTMLファイル（Tailwind CSS CDN + Noto Sans JP フォント利用、外部JSファイル不要で完結）に以下の構造を実装する。

1.  **ヘッダー＆コントロールバー（`header`）**
      - **左上エリア**：
          - バッジ類（例：`Gemini 4 Argon 日本語能力チェック` 等のモデル検証バッジ、`スキャフォールディング教材`、`日本語スピーチコントロール`）。
          - ページタイトル（例：`原文 vs JLPT全10段階（N5前半〜N1後半）比較ビューア`）。
          - サブ説明文（モデル検証時は `本ページは、〇〇 の日本語能力をチェックするために作成したものです。`）。
      - **右上エリア（運営者表記＋モード切替＋ハイライトトグル）**：
          - **運営者表記（右上・必須）**：モード切替ボタンのすぐ上の段（`text-xs text-slate-600 font-medium`）に、以下のリンク付きクレジットを必ず配置する。
            ```html
            <div class="text-xs text-slate-600 font-medium"><a href="https://www.i-seifu.jp/" target="_blank" rel="noopener" class="hover:underline hover:text-blue-700">清風情報工科学院</a> / <a href="https://note.com/norito_hiraoka/" target="_blank" rel="noopener" class="hover:underline hover:text-blue-700">清風AI研究所</a></div>
            ```
          - **表示モード切替ボタン**：`段落ごと原文比較` / `主要表現マトリクス（N段階）` / `全N段階一覧`。
          - **変更ハイライト表示トグル**：`document.body.classList.toggle('hide-highlights', !this.checked)` でハイライト表示のON/OFFを切り替えるチェックボックス。
      - **下部バー（ハイライト凡例）**：`.hl-orig`, `.hl-vocab`, `.hl-grammar`, `.hl-match` の4種凡例を常時表示。

2.  **「このページについて」セクション（`#aboutPage`・必須）**
      - `<main>` の最上部（レベル選択ボタンバーの上）に、ページの目的と操作方法を案内する `#aboutPage` カードを必ず配置する。
      - テンプレート構造：
        ```html
        <section id="aboutPage" class="mb-6 bg-white p-4 rounded-xl border border-slate-200 shadow-sm text-sm text-slate-700 leading-relaxed">
          <h2 class="text-sm font-bold text-slate-900 mb-1.5">このページについて</h2>
          <p>与えた文章を日本語能力 N5前半から N1後半までの10段階で書き分けさせてみました。原文を各レベルで表現し直すとどうなるか、どこがどのように変わるかが分かるようになっています。</p>
          <ul class="list-disc list-inside mt-2 space-y-1">
            <li>「比較するJLPTレベルを選択」の各ボタンを押すと、そのレベルの表現が出ます。</li>
            <li>右上の「主要表現マトリクス（10段階）」を押すと、主要な表現が各レベルでどうなるかが分かります。</li>
            <li>右上の「全10段階一覧」を押すと、各レベルの全文を一覧で比較できます。</li>
          </ul>
        </section>
        ```
        （※特定のAIモデル（例：`Gemini 4 Argon`）の日本語能力チェック目的で作成する場合は、1文目を「〇〇 の日本語能力を確かめるために、与えた文章を〜」とする。また指定レベル数 $N$ に応じて段階数の表記を合わせる）

3.  **レベル選択ボタンバー（`#levelSelectorBar` / $N \ge 2$ の場合のみ表示）**
      - 各ボタンに `lv.code`（例：`1. N5前半`）、到達度 `lv.reach%`、および標準ラベル `lv.sub`（例：`入門、みんなの日本語13課相当`）を表示する。

4.  **ビュー1：段落ごと原文比較モード（`#view-section`・デフォルト表示）**
      - **① 原文カード（`#originalTextCard`・常時表示・必須）**：
          - レベル概要カードの**上**に、選択レベルを切り替えても常に全文を通読・参照できる「【原文】カード」を配置する。
          - ヘッダー左に `【原文】...`、右に緑のバッジで `客観レベル：9. N1前半（上級、ビジネス日本語）相当` のように統一表記を表示。
          - 本文は `originalData.sections` の全段落（`.hl-orig` ハイライト付き）を結合して表示。
          - 出典URLや出典名がある場合は、カード下部に `出典：<a href="...">...</a>` として明記する（ない場合は出典行を省略可）。
      - **② レベル概要カード（`#levelSummaryCard`）**：
          - 選択中のレベルの `lv.code`（例：`1. N5前半`）、標準ラベル `lv.sub`（例：`入門、みんなの日本語13課相当`）、文字数・文数統計 `lv.stats`、原文到達度プログレスバー（`lv.reach%`）、「📐 文法・文構造のコントロール指針」「🔑 語彙アンロック状況」を表示。
      - **③ 3カラム比較カード（`#sectionCardsContainer`・セクションごと）**：
          - 左カラム（5/12幅）：見出しを `【原文】（9. N1前半（上級、ビジネス日本語）相当）` のように統一表記にし、本文（`.hl-orig` 付き）を表示。
          - 中カラム（4/12幅）：`【${lv.code} 変換テキスト】`（`.hl-vocab`, `.hl-grammar`, `.hl-match` 付き）
          - 右カラム（3/12幅）：`🔍 原文との差分・到達ポイント`（箇条書きで解説）

5.  **ビュー2：主要表現マトリクスモード（`#view-matrix`）**
      - 原文の核となる主要フレーズ（4〜5箇所）を列にとり、最上段の「【原文】」行（左セルに `【原文】` と `9. N1前半（上級、ビジネス日本語）相当` の統一表記）に対して、指定された $N$ 個のレベル（`lv.code` ＋ `lv.sub` ＋ 到達度 `%`）を行として並べる。

6.  **ビュー3：全段階一覧モード（`#view-all`）**
      - 最上段（`md:col-span-2` のダークカード `bg-slate-900 text-white`）に「`【原文】〇〇（客観レベル：9. N1前半（上級、ビジネス日本語）相当）`」と出典リンクを配置し、その下に指定された $N$ 個のレベルの全文カードを2カラムグリッドで並べる。

7.  **フッター（運営者表記・画面下中央・必須）**
      - `</main>` の直後に、画面下中央のフッターとして以下のリンク付きクレジットを必ず配置する。
        ```html
        <footer class="max-w-7xl mx-auto px-4 mt-12 pt-6 border-t border-slate-200 text-center text-sm text-slate-600">
          <a href="https://www.i-seifu.jp/" target="_blank" rel="noopener" class="hover:underline hover:text-blue-700">清風情報工科学院</a> / <a href="https://note.com/norito_hiraoka/" target="_blank" rel="noopener" class="hover:underline hover:text-blue-700">清風AI研究所</a>
        </footer>
        ```

### 4\. HTMLコードの出力

  - 省略（`// ...省略...` など）を一切行わず、ブラウザで開いて即座に動作する完全なHTMLコードを出力する。
  - JavaScriptの `levelsData` 配列には、**ユーザーが指定したレベルのデータのみ**を格納し、各オブジェクトに `code`（例：`"1. N5前半"`）と `sub`（例：`"入門、みんなの日本語13課相当"`）を持たせてUI各所に反映させること。

## Gotchas

  - **原文の客観レベル表記（4か所）の不一致防止**：原文カード右上ラベル、段落比較左列見出し、マトリクス表の原文行、全段階一覧の原文カード見出しの4か所は、必ず `9. N1前半（上級、ビジネス日本語）相当` のように `【番号. JLPT表記（標準ラベル）相当】` の完全同一フォーマットで揃えること（JavaScript内で `originalData.levelLabel = "9. N1前半（上級、ビジネス日本語）相当"` のように変数化して4か所に埋め込むと確実）。
  - **3つの定番要素の欠落防止**：
    1. ヘッダー右上およびフッター中央の「**清風情報工科学院 / 清風AI研究所**」のリンク表記
    2. `<main>` 冒頭の「**このページについて**（`#aboutPage`）」セクション
    3. `#view-section` 最上部（レベル概要カードの上）の「**【原文】全文カード**（`#originalTextCard`）」
    これら3つはすべての生成ビューアで必ず含めること。
  - **指定外レベルの混入禁止**：「N3前半にして」「書き言葉レベルにして」と言われた時は `levelsData` の要素数は必ず `1` にする。「入門、初級前半、初級後半にして」と言われた時は要素数を必ず `3` にする。不要なダミーレベルや未指定レベルを入れてはならない。
  - **ボタンレイアウトの崩れ防止**：`levelsData.length` に応じて、ボタンコンテナのクラスを動的に設定する。ボタン内のサブタイトル文字列（`入門、みんなの日本語13課相当` など）が長いため、`truncate` は使わず `text-[11px] opacity-85 mt-1 leading-tight w-full` で折り返して全文読めるようにスタイリングすること。
  - **JSX/HTML属性のエスケープ**：JavaScriptの文字列リテラル内にHTMLタグやダブルクォーテーションを含める際は、バッククォート（テンプレートリテラル）を使用し、属性値のクォート競合による構文エラーを防ぐこと。
